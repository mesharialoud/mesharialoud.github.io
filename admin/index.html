GitHub token

Pushing needs a personal access token limited to this one repository. It is stored only in this browser, never on the site.

  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: site-editor. Expiration: your choice (e.g. 1 year).
  3. Repository access: Only select repositories → mesharialoud.github.io
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token, copy it and paste it below.
