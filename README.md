# mesharialoud.com

Static personal site (HTML/CSS/JS, English + Arabic). Hosted on GitHub Pages at www.mesharialoud.com.

Edit contact links at the top of `script.js`.

## Text editor
Open `/admin/` (https://www.mesharialoud.com/admin/) to edit the English and Arabic text with a live preview, review the changes, and push to GitHub. It needs a fine-grained GitHub token (Contents: read & write on this repo), stored only in the browser.
